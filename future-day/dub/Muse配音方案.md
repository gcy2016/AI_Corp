## 目标
给 `未来的一天.mp4`（8 分 17 秒，1920×1080，无声，字幕已烧录在画面里）配上中文语音，台词和时间点与字幕完全一致，输出 `未来的一天_配音版.mp4`。

## 第 0 步：获取视频和文件
需要的三个文件都在 GitHub 仓库 `gcy2016/AI_Corp` 的 `future-day/` 目录里：

| 文件 | 仓库路径 |
|---|---|
| 无声视频 | `future-day/未来的一天.mp4` |
| 配音脚本 | `future-day/dub/dub.py` |
| 字幕时间轴 | `future-day/src/timeline.json` |

两种获取方式，任选一种：
- **网页下载**：登录 gcy2016 账号，打开 https://github.com/gcy2016/AI_Corp/tree/main/future-day，分别点进上面三个文件，点右上角的下载按钮（Download raw file）。视频较大（几十 MB），等下载完成再继续。
- **命令行**：`git clone https://github.com/gcy2016/AI_Corp.git`（已经克隆过就在仓库目录里运行 `git pull`），三个文件就在 `AI_Corp\future-day\` 下。

下载后把三个文件放进同一个文件夹（见方案 A 第 4 步）。

## 方案 A（首选，全自动）：运行脚本
1. 确认电脑上有 Python 3.9+：终端运行 `python --version`。
2. 安装 ffmpeg（已装可跳过）：`winget install Gyan.FFmpeg`，装完**重新打开终端**，运行 `ffmpeg -version` 确认。
3. 安装语音库：`pip install edge-tts`（需要联网）。
4. 新建文件夹（如 `D:\未来的一天`），放入第 0 步拿到的三个文件：`未来的一天.mp4`、`dub.py`、`timeline.json`。
5. 在该文件夹打开终端，运行 `python dub.py`。会逐句显示进度，共 74 句，大约 3–5 分钟。
6. 结束时出现“完成 → 未来的一天_配音版.mp4”。如果最后列出“需要人工听一下的句子”，验收时重点听这几句。
7. 按下方清单验收，通过后把 `未来的一天_配音版.mp4` 交给噜噜小兵。

常见问题：
- `No module named edge_tts`：改用 `python -m pip install edge-tts`。
- 找不到 `ffmpeg` / `ffprobe`：重新打开终端；还不行就重启电脑。
- 之前跑过旧版本：直接重跑即可，脚本按台词内容缓存，顺序和台词改过的句子会自动重新合成。
- 网络报错或 403：edge-tts 需要连接微软语音服务，换个网络重试。中途失败可以直接重跑，已生成的句子会跳过。
- 某句语气不满意：删掉 `dub_tmp` 里对应编号开头的 `xxx_….raw.mp3`，修改 `dub.py` 里 `VOICES` 的语速后重跑。

## 方案 B（备选，手动）：剪映专业版
1. 新建项目，导入第 0 步下载的 `未来的一天.mp4`，放到主轨道。
2. 「文本」→「本地字幕」导入 `未来的一天.srt`（仓库路径 `future-day/src/未来的一天.srt`，下载方式同第 0 步）。
3. 把导入的字幕轨道**设为隐藏或透明度 0**，画面里已经有字幕，避免出现两层。
4. 按下面的台词表，旁白句选沉稳男声，AI 助手句选柔和女声，居住者句选另一个自然男声，分别「朗读」。
5. 检查每段语音开头与字幕对齐；偏长的句子变速 1.1–1.2 倍。
6. 导出：1080P、30fps、MP4，命名为 `未来的一天_配音版.mp4`。
