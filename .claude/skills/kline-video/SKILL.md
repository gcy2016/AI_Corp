# K 线短视频（如果 X 是一只股票）

用户在 2026-10-24/25 的对话里和 Claude 一起做出了这套视频：《如果中国历史是一只股票》A/B/C 三版、《如果姜子牙是一只股票》。这里记下做法和用户的要求，新对话照着做就能达到同样的效果。

## 一、现成的东西（先用，不要重写）

- **程序**：AI_Corp 仓库 `china-kline/`（说明见 `china-kline/README.md`，方案和数据依据见 `china-kline/PLAN.md`）。
  - `src/film.js`：逐帧绘制引擎（Canvas 2D），所有版本共用。一般不用改。
  - `src/data.js`：基础数据和默认文字（A 版：中国历史，夏 → 1949）。
  - `src/data_b.js`、`data_c.js`：在 A 版基础上打补丁。
  - `src/data_jzy.js`：**做新题材时照它写**，它整体替换了事件、章节和画面文字，是最完整的模板。
  - `src/film.html`：预览和渲染入口，地址参数 `?b`、`?c`、`?jzy` 选版本。新版本要把 id 加进第 21 行的正则 `(b|c|jzy)`。
  - `src/render.js`：渲染。`VER=<id>` 选版本。
  - `tools/make_fonts.py`：字体子集（片中用到的字）。`tools/beats.py`：测配乐节拍。
- **配乐**：`gcy2016/file-storage` 仓库 `cn-kline-bgm-20261024` 分支的 `china-kline/bgm.mp3`（3 分 13 秒，112.81 BPM，BEAT = 0.5319，PHASE = 0.365，17.39 秒鼓点进来）。拷到 `china-kline/bgm.mp3`（已在 .gitignore）。这个分支可能已被 Muse 清理；找不到就请用户重新发音频，再用 `tools/beats.py` 测节拍。用户说“配乐还用之前那个”就是这首。
- **参考视频的画面结构**（用户给过的两个参考：《如果霍去病是一只股票》《大清》）：大字标题 → 股票信息卡（代码、上市时间、发行价、引言 + “买入”印章）→ 集合竞价 100.00 → 鼓点进来时“开盘” → 交易界面（顶部年份和价格、中间 K 线和事件标注、下方当前名号/朝代 + 大事记、底部快讯滚动条）→ 大字转场 → 全景走势金线 + 复盘报告 → 结束语。红涨绿跌，深色背景。

## 二、做一个新版本的步骤

1. **定题材和口径，先跟用户确认**：指数衡量什么（人物 = 身份/声望的“人生指数”；朝代/历史 = 百姓生活的“民生指数”），起止时间，停在哪里，有没有要发抖音的版本（见第四节）。PRD 不清楚时指出来，不要自己扩大范围。
2. **查史料，列时间轴**：每根大 K 线一个事件，写年份、标注（4–7 字）、副标题（出处或说明）、指数值。生前/在位的事尽量多（用户原话：“生前的话就尽量的多”）。传说要标“传说”，年份不确定写“约”。数值写进 PLAN 或交付说明，让用户能看到依据。
3. **按节拍排时间**：第 b 拍的时间 = PHASE + b × BEAT。第 0–32 拍是开场；之后每 32 拍（8 小节，约 17 秒）一章，共 6 章（第 32、64、96、128、160、192 拍开始）；第 224 拍出全景（大字如“四千年”“三千年”）；第 256 拍出结束语。片长 146 秒（音乐 142 秒起淡出）。要更长就再加章节，B 版加到 8 章、片长 184 秒（音乐约 168 秒起自然淡出）。
   - 每章 5–9 根大 K 线，间隔 3–6 拍；大 K 线自动占 3 拍走“盘中”行情，空出来的拍子自动补小 K 线。
   - 关键时刻（暴涨、暴跌、转折）加 `big: ['大字', '副标题']`，放在**小节重拍**（拍号是 4 的倍数）上；和章节开头撞了就用 `bigAt` 往后挪。
4. **写数据文件** `src/data_<id>.js`，照 `data_jzy.js`：
   - `EVENTS`：`{ b, y, era, t, s, v, abs: true, big?, bigAt?, last? }`。`y` 是年份文字（公元前写“前1046”，开头必须是“前”或数字，否则顶部年份显示不对）；`era` 是朝代或阶段；最后一根加 `last: true`。
   - `CHAPTERS`：6 个 `{ name, b0, mark }`，`mark` 是 K 线背后的水印大字。
   - `PANO_LABELS`：全景金线上要标的点（开盘、低谷、巅峰、转折、收盘），用事件标注 `t` 找序号。
   - `VERSION`：`span`（如“前1156 – 清”）、`years`、`endYear`、`ddText`（最大回撤说明）、`pano`（全景对数坐标的 `lo`、`hi`、`grid`，要罩住全部数值）、`live`（结尾是否“交易中”）、`panoStamp`、`closeStamp`。
   - `TX`：画面固定文字：印章字、股票名、代码、板块、指数名、K 线周期、名号栏标题、开场两行大字、标语、信息卡的问句和 6 行内容、引言（2–3 行）和出处、开盘副标题、全景大字、复盘报告的三个标签、结束语两行和出处、结束语下面那句话。
   - 最后设 `TREND_SLOPE`（人物版设 0，所有值用 `abs: true` 直接给）和 `TICKER`（快讯：免责声明“××指数为艺术化演绎，非真实数据”、史料出处、哪些是传说）。
5. **重新生成字体子集**（新字不在子集里会显示成别的字体）：先 `pip install fonttools brotli`，再在临时目录 `npm pack @fontsource/noto-serif-sc @fontsource/noto-sans-sc` 并解压，然后对 serif 900/700、sans 400/500/700 各跑一次：
   `python tools/make_fonts.py <解压目录> x 900 fonts/NotoSerifSC-900.woff2 src/data.js src/data_b.js src/data_c.js src/data_jzy.js src/data_<id>.js src/film.js`（命令行要列出所有数据文件，别把旧版本的字丢了）。
6. **先看截图再渲染整片**：`cd china-kline/src && VER=<id> NODE_PATH=$(npm root -g) node render.js stills 3 12 30 50 70 90 110 125 133 140`，用 ffmpeg 拼起来看。检查：开场文字、信息卡引言有没有出框、标注是否重叠、大字转场时机、全景标签和印章有没有压线、复盘数字对不对。动效用 `clip 36 39 <out.mp4>` 渲染一小段，再按 10fps 拆帧看。
7. **渲染整片**：`VER=<id> NODE_PATH=$(npm root -g) node render.js video ../out/<name>.mp4 ../bgm.mp3`（约 2.5–3.5 分钟）。Playwright 用 Node 版（全局已装，所以要 `NODE_PATH`），不用 Python 版。
8. **交付**：视频推到 file-storage 的新分支（见 AI_TEAM.md “例外：Claude 用 git 分支上传”，分支名英文，用 `git init` 建一个只放这个文件的新分支，推完用 `git ls-remote` 核对）；用 SendUserFile 把 mp4 发给用户；代码提交到 AI_Corp 的工作分支。回复里写清：走势分几章、关键数字、停在哪里、哪些是传说或估计、文件链接。删除分支由 Muse 负责，不用问。

## 三、用户在这次对话里定下的要求（都要遵守）

**走势口径**
- 历史/朝代题材用**人民史观**：不判断哪个政权正义，百姓日子变好就涨，受苦就跌，多民族政权一视同仁。
- 要有**长期向上的趋势**：生产力和技术一代代积累，后来的乱世起点比几百年前的乱世高。第一版没加趋势，1949 年收盘比夏朝开盘价还低（“破发”），被用户指出来了。做完一定检查：收盘价有没有低于发行价、明显进步了的时代有没有反而比早期还低。
- 但**不要夸张**：用户批评过别人的视频（清帝退位时涨了二三十倍，之后只画一根模拟趋势线）。走势要接近真实，每根 K 线都按史实画，不用模拟线糊弄。只有用户明确要“好看一些”的版本（如 C 版）才放大趋势、减轻跌幅，并在说明里写清楚调了什么。
- **人物题材**：生前起伏按事迹画；去世要跌，但**不能跌得太狠**（姜子牙版先跌了 76%，用户嫌“都给他跌没了快”，改成约 40%）；身后若有追封、祭祀、民间信仰，要一路涨，**身后最高点要明显高过生前最高点**（姜子牙版身后 4800，是生前巅峰 1080 的 4 倍多）。结尾停在身份最高点或最后一个王朝，由 Claude 判断后说明理由。
- 数值和用户想法不一致时，如实说明怎么算的、哪里错了，再改；用户没要求改就不要擅自改数据。

**动效（用户特别强调过）**
- 每根 K 线都要有**盘中走势**：价格上下抖动，影线随走过的最高/最低价逐步长出来，坐标轴跟着缩放，顶部价格跟着跳，最后定在收盘价。大 K 线约 1.5 秒，小 K 线约半秒。
- **偶尔红绿变色**：约三分之一的 K 线先反向走一段再拉回（阳线中途变绿、阴线中途变红），不是每根都这样。
- 这些已经写在 `film.js` 的 `pathAt` / `candleAt` 里，新版本自动带上，不要改回静态。
- 所有转场、暴涨暴跌、大字都要**踩在配乐的拍子上**，和参考视频一样。

**内容和尺度**
- 只有背景音乐，**不要配音**。
- 要发抖音的版本：中国题材**不碰 1949 年以后**，1949 年以前的敏感处写稳妥（如明清易代只写“战乱”，不写屠城细节；不单独画国共内战）。用户一度连清帝退位以后都不想提（C 版停在 1912 年，片中不能出现“民国”）。自己看的版本可以完整、具体（死亡人数写学术估计区间并注明是估计）。做之前问清楚是哪种。
- 用户可能会说“我自己看，不往外发”，这时按史实完整做，但敏感内容仍要准确、中立。

## 四、容易出错的地方

- **改 AI_TEAM.md 或往别的仓库推东西时**，严格按 AI_TEAM.md 开头的提示做（这次对话里两次因为用 `--no-checkout` 克隆后提交，把仓库其他文件全删了）。
- `film.js` 里的文字都走 `TX` 配置，新版本不要直接改 `film.js` 里的中文；要加新的画面元素再改 `film.js`，改完对 A 版截几张图，和旧视频比对，确认没被影响。
- 新版本的 id 要加进 `film.html` 的正则，否则 `VER=<id>` 不生效，渲染出来还是 A 版。
- 字体子集漏字会显示成文泉驿字体，截图里能看出来：标题不是宋体就是漏了。
- `y` 年份文字前面别加“约”（放进副标题 `s` 里）。
- 全景 `pano.hi` 要大于最高值，`lo` 要小于最低值，否则金线出框。
- 渲染前先把 `china-kline/bgm.mp3` 准备好；`render.js` 会按 `AUDIO_FADE` 淡出。
