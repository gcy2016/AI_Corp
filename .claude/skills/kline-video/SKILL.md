# K 线短视频（如果 X 是一只股票）

用户在 2026-10-24/25 的对话里和 Claude 一起做出了这套视频（中国历史 A/B/C 三版、姜子牙、霍去病、国足）。这里记下做法和用户对所有 K 线视频的通用要求，新对话照着做就能达到同样的效果。每个题材自己的口径（指数衡量什么、停在哪里、尺度）每次跟用户单独确认，不要套用以前题材的结论。

## 一、现成的东西（先用，不要重写）

- **程序**：AI_Corp 仓库 `china-kline/`（说明见 `china-kline/README.md`）。
  - `src/film.js`：逐帧绘制引擎（Canvas 2D），所有版本共用。一般不用改。
  - `src/data.js`：基础数据和默认文字（A 版：中国历史）。所有可配置项的默认值都在这里。
  - `src/data_<id>.js`：各版本。**做新题材照 `data_jzy.js`（姜子牙）写**，它整体替换了事件、章节和画面文字，用到了 `via`、`hit`、`fall` 等全部写法。
  - `src/film.html`：预览和渲染入口，地址加 `?<id>` 就加载 `data_<id>.js`。
  - `src/render.js`：渲染并混音。`VER=<id>` 选版本。
  - `tools/make_fonts.py`：字体子集。`tools/beats.py`：测配乐节拍。`tools/extract_accent.py`、`tools/extract_drum.py`：从参考视频/配乐里提取音效。`tools/accent.py`：合成陨落音。`tools/make_nodrums.py`：生成去鼓版配乐。
- **本技能目录里的素材**（`.claude/skills/kline-video/`）：
  - `bgm.mp3`：固定配乐（3 分 13 秒，112.81 BPM，BEAT = 0.5319，PHASE = 0.365，17.39 秒鼓点进来）。
  - `accent.wav`：高光强调音（从诸葛亮参考视频赤壁之战处提取的原声）。
  - `fall.wav`：陨落重击音（合成）。
  - `drum.wav`：连板鼓点（从配乐开盘鼓点提取）。
  - `bgm_nodrums.mp3`：去掉鼓的配乐，连板锁定区间里用。
  - 渲染时把 `bgm.mp3` 的路径作为最后一个参数，`render.js` 会自动从同一目录找这三个音效。
- **参考视频的画面结构**（用户给过：霍去病、大清、诸葛亮、吕布）：封面 → 股票信息卡（代码、上市时间、发行价、引言 + “买入”印章）→ 集合竞价 100.00 → 鼓点进来时“开盘” → 交易界面（顶部年份和价格、中间 K 线和事件标注、下方当前名号 + 大事记、底部快讯）→ 大字转场 → 全景走势金线 + 复盘报告 → 结束语。红涨绿跌，深色背景。

## 二、做一个新版本的步骤

1. **定题材和口径，先跟用户确认**：指数衡量什么、起止时间、停在哪里、涨跌依据、有没有不能碰的内容。PRD 不清楚时指出来，不要自己扩大范围。
2. **查资料，列时间轴**：每根大 K 线一个事件，写年份、标注（4–7 字）、副标题（出处或说明）、收盘值。资料能查到多少就尽量多用。传说标“传说”，年份不确定写“约”。数值和依据写进交付说明。
3. **定“一根 K 线”的时期**：横轴按时间顺序。同一时期内（通常同一年，或紧挨着、属于同一件事）的几件事合并成一根 K 线；如果这几件事方向相反（先跌后涨、先涨后跌），用 `via` 写出盘中途经点。多长算同一时期由 Claude 按题材判断，在交付说明里写清楚。
4. **按节拍排时间**：第 b 拍的时间 = PHASE + b × BEAT。第 0–32 拍是开场；之后每 32 拍（8 小节，约 17 秒）一章，共 6 章（第 32、64、96、128、160、192 拍开始）；第 224 拍出全景；第 256 拍出结束语。片长 146 秒（音乐 142 秒起淡出）。要更长就加章节（8 章、片长 184 秒，音乐约 168 秒起自然淡出）。
   - 每章 5–9 根大 K 线，间隔 3–6 拍；空出来的拍子自动补小 K 线。
   - 关键时刻加 `big: ['大字', '副标题']`，放在**小节重拍**（拍号是 4 的倍数）上；和章节开头撞了就用 `bigAt` 往后挪。
5. **写数据文件** `src/data_<id>.js`，照 `data_jzy.js`：
   - `EVENTS`：`{ b, y, era, t, s, v, abs: true, via?, boards?, big?, bigAt?, hit?, fall?, last? }`
     - `y` 年份文字（公元前写“前1046”，开头必须是“前”或数字，“约”放进副标题 `s`）；`era` 阶段；`v` 收盘值；最后一根加 `last: true`。
     - `via: [途经点…]`：同一时期内的反转，K 线依次走过开盘 → 途经点 → 收盘。
     - `boards: [[事件, 说明], …]`：同一时期几件事叠出来的大阳线，按连板画（见第三节）。
     - `hit: true`：一件大事直接拉起来的高光时刻，叠强调音（见第三节）。
     - `fall: true`：从巅峰跌入谷底的陨落、大反转，触发陨落效果（见第三节），很少用。
   - `CHAPTERS`：6 个 `{ name, b0, mark }`，`mark` 是 K 线背后的水印大字。
   - `PANO_LABELS`：全景金线上要标的点（开盘、低谷、巅峰、转折、收盘），用事件标注 `t` 找序号。
   - `VERSION`：`span`、`years`、`endYear`、`ddText`（最大回撤说明，留空就自动生成）、`pano`（全景对数坐标的 `lo`、`hi`、`grid`，要罩住全部数值）、`live`（结尾是否“交易中”）、`panoStamp`、`closeStamp`。
   - `TX`：画面固定文字。`cover` 是封面三行大字，每段 `[文字, 颜色]`，颜色 `w` 白、`g` 金、`r` 红，例如 `[[['如果把','w'],['姜子牙','g'],['的人生','w']], [['画成','w'],['K线','r']], [['会是什么样？','w']]]`，主题词用金色、“K线”用红色，第一行按题材改措辞；`disclaimer` 免责小字；以及股票名、代码、板块、指数名、K 线周期、名号栏标题、信息卡问句和 6 行内容、引言（2–3 行）和出处、开盘副标题、全景大字、复盘报告的三个标签、结束语。
   - 最后设 `TREND_SLOPE`（直接给数值的版本设 0，所有事件 `abs: true`）和 `TICKER`（快讯：“××指数为艺术化演绎，非真实数据”、资料出处、哪些是传说）。
6. **重新生成字体子集**：先 `pip install fonttools brotli`，在临时目录 `npm pack @fontsource/noto-serif-sc @fontsource/noto-sans-sc` 并解压，然后对 serif 900/700、sans 400/500/700 各跑一次：
   `python tools/make_fonts.py <解压目录> x 900 fonts/NotoSerifSC-900.woff2 src/data*.js src/film.js`（列出全部数据文件，别把旧版本的字丢了）。
7. **先看截图再渲染整片**：`cd china-kline/src && VER=<id> NODE_PATH=$(npm root -g) node render.js stills 0 8 12 30 50 70 90 110 125 133 140`，拼起来看：封面、信息卡引言（不能和标签、出处重叠）、标注是否重叠、大字时机、全景标签和印章、复盘数字。动效和踩点用 `clip <起> <止> <out.mp4> <bgm>` 渲染一小段，按 10–15fps 拆帧看。
8. **核对踩点**（必须做）：用 node 加载 `data.js`、`data_<id>.js`、`film.js`，对每根带 `hitB` 的 K 线算出价格冲过整段涨跌一半的时间，和 `HITS`/`FALLS` 里的音效时间比，相差要在 0.1 秒以内；`DRUMS` 要和每一板封板（`boardTimes`）是同一拍。
9. **渲染整片**：`VER=<id> NODE_PATH=$(npm root -g) node render.js video ../out/<name>.mp4 ../../.claude/skills/kline-video/bgm.mp3`（约 2.5–3.5 分钟，输出里会打印 accent hits / falls / drums 的时间）。
10. **交付**：视频推到 file-storage 的新分支（见 AI_TEAM.md “例外：Claude 用 git 分支上传”，用 `git init` 建一个只放这个文件的新分支，推完用 `git ls-remote` 核对）；用 SendUserFile 把 mp4 发给用户；代码提交到 AI_Corp。回复里写清：走势分几章、关键数字、同一时期怎么合并的、停在哪里、哪些是传说或估计、文件链接。删除分支由 Muse 负责，不用问。

## 三、所有 K 线视频的通用要求（用户定的）

**声音**
- **配乐**：默认用本技能目录里的 `bgm.mp3`，以后都用这首，除非用户特别说明。只有背景音乐，没有配音。换配乐时用 `tools/beats.py` 重新测节拍，改 `data.js` 的 BEAT、PHASE 和片长。
- **踩点**：所有转场、章节开头、暴涨暴跌、大字都踩在配乐的拍子上。大字放在小节重拍上。
- **高光强调音**（`accent.wav`）：高光时刻的大阳线标 `hit: true`，在它的大字出现那一拍叠强调音。一个视频 3–5 处为宜。
- **结束交易就停**：人物去世、对象终结（`VERSION.live: false`，最后一根 `last: true`）之后不再出新 K 线，画面定住，只让配乐从发闷恢复清晰、画面恢复颜色，然后进全景。还在继续的题材（`live: true`）才在最后一根之后继续走小 K 线。
- **陨落效果**（`fall.wav` + 画面 + 闷音）：从巅峰直接跌入谷底的反转、陨落，标 `fall: true`。那一拍重击一声，配乐立刻发闷（低通），同时画面闪白、整帧褪成黑白，大字红蓝错位、横向撕裂，约 1 秒后稳定。到下一章开始时（至少 6 拍、最多 12 拍）声音和颜色一起恢复清晰；后面没有 K 线时也要在视频结束前恢复。这种大阴线很少，一个视频最多一两处。
- **连板与鼓点**（`drum.wav`）：只有当一根大阳线是**同一时期里几件事叠出来的**（确实在同一时期接连取得多个高光成就），才用连板画法：数据里写 `boards: [[事件, 说明], …]`，这根 K 线每拍（约 0.53 秒）往上封一板，每封一板落一个“涨停”印章、旁边写这一板涨的原因，“二连板、三连板……”跟着变；**三板及以上**每封一板配一声鼓，两板不加鼓。一件大事直接拉起来的大阳线不做连板，用高光强调音（`hit: true`）。**不要为了做连板硬凑数据**：不同时期的事件不要合并，中间有小 K 线就不是连板，K 线该怎么走就怎么走。例：霍去病前123 年“剽姚校尉 → 轻骑八百 → 斩首二千 → 封冠军侯”是同一次出征，叠成一根四连板。
- **连板锁定区间**：配乐本身有鼓，叠上连板鼓点会乱。所以从第一声连板鼓前 0.15 秒到最后一声后 0.4 秒，配乐自动换成去鼓版 `bgm_nodrums.mp3`（只去鼓，旋律和声都在），区间内只听得到间隔固定的连板鼓点，结束后切回原曲（`film.js` 的 `LOCKS`，`render.js` 交叉淡化）。换配乐时用 `tools/make_nodrums.py` 重新生成去鼓版。
- **音效、大字、K 线三者对齐**：有大字、强调音或陨落效果的 K 线，暴涨暴跌的那一下必须和大字出现、音效响起是同一帧（半拍内冲到位，再小幅回落定住），镜头推近也在这一拍。不能 K 线先跳、音效后响，也不能音效先响、K 线慢慢才涨。`film.js` 里由 `hitB`（= 事件的 `bigAt` 或 `b`）控制：`hitB` 之前蓄势（有 `via` 就先走到途经点），`hitB` 那一刻爆发。

**K 线画法**
- **影线 = 这一时期实际走到过的最高价和最低价**，实体 = 开盘到收盘。不能随手加长影线。
- **同一时期内的反转要画出来**：先跌后涨就是长下影线、先绿后红；先涨后跌就是长上影线、先红后绿。用 `via`。
- **盘中走势**：每根 K 线都有开盘后的走势：价格上下抖动，影线随走过的最高/最低价长出来，坐标轴跟着缩放，顶部价格跟着跳，最后定在收盘价。大 K 线约 1.5 秒，小 K 线约半秒。
- **偶尔红绿变色**：约三分之一的 K 线先反向走一段再拉回，不是每根都这样。
- **镜头推进和缩放**：开头 K 线少时近景，越多越拉远，常态最多同时看到约 24 根（聚焦最近的部分，不要照顾太早的 K 线）；重大的大阳线、大阴线（有大字、强调音、陨落，或单根涨跌超过 25%）时，在那一拍推近到约 9 根，停 3 拍后用 5 拍拉回。
- 以上都已写在 `film.js` 里（`pathAt` / `candleAt`、`nwin` 的 `ZOOM_IN`/`WIN_MIN`/`WIN_MAX`、`HITS`/`FALLS`/`DRUMS`、`fallFx`），新版本自动带上，不要改回去。

**画面**
- **封面**：第一帧就是完整封面，三行粗体大字“如果把〔主题〕…… / 画成K线 / 会是什么样？”，主题词金色、“K线”红色，背后衬一条淡金色的全片走势简图，下面一条细线和免责小字。
- **免责小字**“内容仅作科普，不构成投资建议”全片都有（封面在细线下，交易界面在名号栏右侧，开场和结尾在底部居中）。
- **文字不能重叠**：引言框按行数自动排版；事件标注撞在一起时自动上下错开。新加画面元素要检查有没有压字。

**数据**
- 走势数值和用户的想法不一致时，如实说明是怎么算的、哪里可能错了，再按用户意见改；用户只是聊看法、没要求改时，不要擅自改数据。

## 四、容易出错的地方

- **改 AI_TEAM.md 或往别的仓库推东西时**，严格按 AI_TEAM.md 开头的提示做（曾两次因为用 `--no-checkout` 克隆后提交，把仓库其他文件全删了）。
- `film.js` 里的文字都走 `TX` 配置，新版本不要直接改 `film.js` 里的中文；改了 `film.js` 要对 A 版截几张图和旧视频比对。
- 字体子集漏字会显示成文泉驿字体，截图里能看出来。
- 全景 `pano.hi` 要大于最高值，`lo` 要小于最低值，否则金线出框。
- 渲染命令最后一个参数是配乐路径，别漏掉，否则没有声音，也不会加音效。
